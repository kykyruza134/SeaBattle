Морской бой
Описание проекта

«Морской бой» — настольная стратегическая игра, реализованная на языке Python с использованием библиотеки PyQt6. Игроки размещают свой флот на игровом поле размером 10×10 клеток и поочередно выполняют выстрелы по полю противника. Побеждает игрок, первым уничтоживший все корабли соперника.

Возможности:
Расстановка кораблей перед началом игры.
Поворот кораблей по горизонтали и вертикали.
Проверка корректности размещения кораблей.
Пошаговый игровой процесс для двух игроков.
Отображение попаданий и промахов.
Автоматическое определение уничтоженных кораблей.
Подсветка подбитых и уничтоженных кораблей.
Определение победителя и завершение партии.
Графический интерфейс пользователя на основе PyQt6.

Правила игры

Каждый игрок располагает следующим флотом:
1 четырехпалубный корабль;
2 трехпалубных корабля;
3 двухпалубных корабля;
4 однопалубных корабля.

Корабли не могут соприкасаться друг с другом ни сторонами, ни углами.

После завершения расстановки начинается фаза боя. Игроки по очереди выбирают клетку на поле противника для выполнения выстрела.

Обозначения:

Пустая клетка — не исследована.
● — попадание.
× — промах.

Игра завершается после уничтожения всех кораблей одного из игроков.

Требования
Python 3.10 или выше
PyQt6

Запуск программы
python main.py

Управление
Фаза расстановки
Левая кнопка мыши — выбор и установка корабля.
Клавиша R — изменение ориентации корабля.
Фаза боя
Левая кнопка мыши по клетке поля противника — выполнение выстрела.

Используемые технологии
Python
PyQt6
